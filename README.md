# Планировщик маршрута

Панель построения маршрута по нескольким точкам (как в Яндекс.Картах): добавление и
перетаскивание точек, выбор способа передвижения, расчёт общей дистанции и времени.
Точки хранятся в локальной базе (**IndexedDB**) прямо в браузере, поэтому проект —
полностью статический и разворачивается на **GitHub Pages** без сервера.

## Что внутри

- **Панель маршрута** — старт (A), промежуточные пронумерованные точки, финиш (B).
  Перетаскивание для смены порядка, удаление, добавление по адресу или координатам.
- **Локальная база (IndexedDB)** — текущий маршрут автосохраняется; можно сохранять
  именованные копии, загружать и удалять их. См. `src/lib/db.ts`.
- **Карта и маршрут** — бесплатный Yandex JS API строит маршрут на клиенте и отдаёт
  общую дистанцию/время. См. `src/components/MapView.tsx`.
- **Оптимизация** — пересборка порядка промежуточных точек методом ближайшего соседа
  (offline-эвристика по прямой). См. `src/lib/geo.ts`.

## Локальный запуск

```bash
npm install
cp .env.example .env      # впишите VITE_YANDEX_API_KEY
npm run dev
```

Без ключа панель и сохранение точек работают; карта показывает подсказку о ключе.
Ключ Yandex JS API бесплатный: developer.tech.yandex.ru. В кабинете ограничьте его
по HTTP Referer вашим доменом (он публичный, так как используется на клиенте).

## Деплой на GitHub Pages

1. Запушьте репозиторий, ветка `main`.
2. Settings → Pages → **Source: GitHub Actions**.
3. Settings → Secrets and variables → Actions → добавьте секрет
   `VITE_YANDEX_API_KEY` со значением ключа.
4. Workflow `.github/workflows/deploy.yml` сам соберёт проект и задаст
   `base = /<имя-репозитория>/` — ручная настройка пути не нужна.

Сайт будет доступен на `https://<username>.github.io/<repo>/`.

## Структура

```
src/
  App.tsx                 состояние, persistence, add/optimize/save/load
  types.ts                Coordinate, RoutePoint, RouteDraft, ...
  components/
    RoutePanel.tsx         левая панель (режимы, точки, действия, сводка)
    MapView.tsx            карта + multiRoute, отдаёт дистанцию/время
  lib/
    db.ts                  IndexedDB (локальная база)
    geo.ts                 haversine + оптимизация порядка
    yandex.ts              загрузка JS API + геокодер
    example.ts             демо-точки при первом запуске
```
